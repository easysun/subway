# Subway 實作計畫

**目標：** 完成可操作的定期支出管理工具，驗證資料計算與帳戶隔離，並交付對應的公開原始碼與私有檢視部署。

**架構：** 共用具型別的日期與金額邏輯；經身份驗證的 HTTP API 將已驗證工作區儲存至 D1；響應式 React 總覽與表單；版本檢查防止過期資料覆蓋。

**技術：** React、TypeScript、Vinext、Cloudflare Workers／D1、Drizzle schema 與 migration、Node 測試。

## 持續檢查的原則

- 1 月 31 日與閏年日期必須保留原始錨點，不能因短月而逐月漂移。
- 提前或延後付款依實際付款月份入帳，同一期的原訂付款不可重複計算。
- 浮動金額未知或缺少匯率時，合計必須標示缺漏，不能默認為 0 元。
- 每次資料讀寫都使用伺服器確認的 owner；每次寫入都檢查 revision。
- 示範資料與帳戶資料分開。公開原始碼不包含使用者記錄或憑證；使用者自行下載的備份則會包含其財務資料，必須明確告知。
